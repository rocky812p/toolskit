# ToolKit - All-in-One Web Tools

A modern, responsive collection of web tools built with HTML, CSS, and JavaScript. This project uses TailwindCSS for styling and includes dark mode support.

## 🚀 Features

- **Calculator**: Basic arithmetic operations with keyboard support
- **Timer**: Countdown timer with notification sound
- **Currency Converter**: Convert between major currencies (mock data)
- **Notepad**: Save and manage notes with localStorage
- **Dark Mode**: System-wide dark mode toggle
- **Responsive Design**: Works on all devices
- **Modern UI**: Smooth animations and transitions

## 🛠️ Technologies Used

- HTML5
- CSS3 (TailwindCSS)
- JavaScript (Vanilla)
- Font Awesome Icons
- LocalStorage API

## 🎯 Usage

### Calculator
- Use mouse or keyboard for input
- Supports basic arithmetic operations
- Clear button (C) to reset

### Timer
- Set hours, minutes, and seconds
- Start/Pause/Reset functionality
- Audio notification when timer ends

### Currency Converter
- Select source and target currencies
- Enter amount to convert
- Quick currency swap button

### Notepad
- Create notes with title and content
- Auto-save functionality
- Edit and delete saved notes
- Dark mode support

## 🌙 Dark Mode

- Click the moon/sun icon in the navigation bar
- Preference is saved in localStorage
- Automatically applies to all tools
